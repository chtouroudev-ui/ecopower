⚡ Comparaison Avant / Après

❌ AVANT – Problèmes

  • Tableau horizontal 1050px (scroll obligatoire)
  • 12+ colonnes mélangées = cognitive overload
  • États en petit texte gris (60px de hauteur)
  • Aucun groupage = 50+ lignes brutes
  • Drill-down campagne = chargement 10s+ API
  • Aucun filtre multi-critères
  • Tri limité (asc/desc/default)
  • Mobile : impossible à consulter

✅ APRÈS – Solutions

  • Responsive max 1366px (zéro scroll horiz)
  • 4 colonnes max = focus immédiat
  • États en badges colorés (hauteur 32px)
  • Groupage par groupe = scan par section
  • KPI flottant = sans drill-down lourd
  • Filtres État/Groupe/Campagne/Texte
  • Tri 3-état (asc/desc/default)
  • Mobile : stack vertical adapté

🎯 Recommandations UX pratiques

1️⃣ Temps réel & Rafraîchissement

  • Agents : 5s (proche du temps réel)
  • Campagnes : 10s (moins de charge backend)
  • Pulse discret (fond clignotant 0.5s) sur changement critère

2️⃣ Tri & Filtres

  • Défaut : "Statut DESC (alertes haut), puis Agent ASC"
  • Sauvegarde : localStorage + URL shareable (`?state=alert&group=MED&sort=agent-asc`)
  • Favori : Bouton ⭐ pour sauvegarder filtre perso

3️⃣ Alertes & Notifications

  • Alerte critique : Badge rouge + couleur fond, aucune modale
  • Son discret : Bip 1s unique par type (connecté, disponible, alerte)
  • Historique : Lien vers "Incidents / Alertes" (section dédiée)

4️⃣ Mobile & Responsive

  • Agents : Stack vertical, masquer "ANI", regrouper États/Pauses
  • Campagnes : 1 colonne grille, KPI panel en-dessous
  • Filtres : Sticky top, drawer sur tap (pas inline)

5️⃣ Accessibilité

  • ARIA labels sur tous boutons/badges
  • Contraste WCAG AA min (4.5:1 texte/fond)
  • Clavier : Tab → filtres → lignes → drill-down
  • Icônes + texte (pas icônes seules)
